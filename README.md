## Установка

1. Откройте [последний релиз](https://github.com/Laconite/sho-po-param/releases/latest) и скачайте файл `.apk` из раздела **Assets**.
2. Откройте скачанный файл и нажмите **Установить**. Если телефон попросит, разрешите установку из неизвестных источников.

Нужен Android 7.0 или новее.
